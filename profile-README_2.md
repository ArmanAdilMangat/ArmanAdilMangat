### 🌟 Featured Project — GENIE

> *"Capabilities once reserved for $50B cloud platforms, running on a $15 board and a laptop."*

🧞 **[GENIE — Offline Voice AI Assistant](https://github.com/ArmanAdilMangat/GENIE)** &nbsp; `Final Year Project · Team Lead`

A fully offline voice assistant on **ESP32-S3** — no cloud, no API keys, all on-prem.

- 🎤 **Hardware:** Dual INMP441 I2S mics · MAX98357A class-D amp · 3W speaker · 8MB PSRAM
- 🧠 **AI Stack:** OpenAI Whisper (STT) → Mistral 7B via Ollama (LLM) → pyttsx3 (TTS)
- ⚡ **Latency:** 8–15s end-to-end · **Cost:** ~$22 hardware · **Privacy:** 100% local
- 🛠️ **10 hard problems solved:** dual I2S bus management, PSRAM overflow (480KB buffers), WiFi audio crackle, ghost-voice distortion (22050→16kHz resample), INMP441 bit-shift tuning
- ✅ **Phase 1:** 16/16 user stories · 10/10 critical bugs resolved
- 🚧 **Phase 2 (mostly done):** ESP-NOW peer-to-peer ✅ · IoT smart-home control ✅ · Stereo mics ✅ · Wake-word & web dashboard pending

`ESP32-S3` `Whisper` `Mistral 7B` `Ollama` `Flask` `I2S Audio` `PSRAM` `Offline LLM`

### 📌 Other Projects

#### 📰 [BERT News Classifier](https://github.com/ArmanAdilMangat/DevelopersHub-AI-Internship-Advance-Tasks)
Fine-tuned **BERT-base-uncased** on AG News (120K samples) using HuggingFace Trainer with fp16 mixed precision on RTX 4060.
**→ 94.74% accuracy · 94.75 macro F1** · batch 16 · lr 2e-5 · 3 epochs

#### 🎫 [LLM Support-Ticket Auto-Tagger](https://github.com/ArmanAdilMangat/DevelopersHub-AI-Internship-Advance-Tasks)
Compared **zero-shot · few-shot · fine-tuned** LLM approaches for ticket classification.
**→ 99.82% accuracy** with fine-tuned model · published reproducible comparison report

#### 📉 [Customer Churn ML Pipeline](https://github.com/ArmanAdilMangat/DevelopersHub-AI-Internship-Advance-Tasks)
End-to-end churn prediction on IBM Telco (7K rows) with ColumnTransformer preprocessing + GridSearchCV (5-fold, F1) comparing Logistic Regression vs Random Forest.

#### 🛡️ [CNN-LSTM Intrusion Detection for IoT](https://github.com/ArmanAdilMangat/Research-paper) &nbsp; `Independent Research`
Hybrid CNN-LSTM with **NSGA-II Jumping-Gene** multi-objective feature selection on CICIDS-2017.
**→ 99.03% accuracy · 5× faster training** vs MLP/CNN baselines
